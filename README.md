### 👨🏻‍💻 &nbsp;Sobre Mi

Desarrollador FullStack JavaScript en formación continua, en transición desde el área de enfermería hacia la tecnología. Mi experiencia previa en salud me permitió desarrollar habilidades clave como el trabajo bajo presión, la atención al detalle, la resolución de problemas y el trabajo en equipo, competencias que hoy aplico en el desarrollo de software para construir aplicaciones web completas, desde interfaces de usuario responsivas hasta arquitecturas backend robustas con autenticación, bases de datos y APIs REST. 
Me apasiona escribir código limpio y aprender constantemente. Actualmente en búsqueda de oportunidad profesional en el área TI, con ganas de aportar valor real a un equipo y seguir creciendo como desarrollador.
